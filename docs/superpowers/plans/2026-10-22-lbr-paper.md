# Paper LBR (Lisy & Bowling 2017) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the sampled-rollout `LbrEvaluator` in `sixmax/src/exploit/lbr.{h,cpp}` with the local best response of Lisy & Bowling, "Equilibrium Approximation Quality of Current No-Limit Poker Bots" (AAAI-17 workshop, `docs/papers/lbr_2017_lisy_bowling_equilibrium_quality_nl_bots.pdf`, Figure 1), so heads-up blueprints get a low-variance lower bound on exploitability.

**Architecture:** LBR keeps the opponent's exact range over the 1,326 combos (Bayes on the blueprint's own action probabilities, reusing `RangeTracker`). At each LBR decision on an acting street it scores call/check and every considered bet with the paper's one-step formula, using exact showdown win probability against the range, and folds when nothing is positive. On non-acting streets it checks or calls. The evaluator plays duplicate hands (LBR in each seat, same deck) against the blueprint and reports LBR's average winnings.

**Tech Stack:** C++20 in `sixmax/` (Buck2 target `//sixmax:sixmax`), pybind11 bindings, pytest.

**Spec:** the paper's Figure 1 and "Computing Lower Bound on Exploitability" section are the spec. The requirements below restate them for this engine.

## Global Constraints

- Heads-up only: `LbrEvaluator` throws `std::invalid_argument` containing "heads-up" if `cfg.num_players != 2`.
- All chip values are BB (engine frame). The evaluator's `EngineConfig` comes from the caller; `scripts/eval_sixmax_lbr.py` uses `strategy.starting_stack()` unless `--stack-bb` is given (already implemented on this branch, commit 96c6fe1).
- The opponent model is `blueprint_probs(strategy, state)` (masked, uniform fallback) from `exploit/policy.h`, evaluated with the opponent's hole cards set to each combo via `HandState::set_hole_cards`. In `uniform_opponents` mode every opponent probability is uniform over the legal mask.
- Hand strength only through `safe_eval::rank7` / `HandRank::beats` / `ties` (`common/src/game/safe_eval.h`). Never touch raw scores.
- `cfr/`, `neural_cfr/`, `sixmax/` never import each other or `game/poker.py`.
- Results are deterministic for a given seed and independent of the thread count.
- Never commit checkpoints, `sixmax/tables/`, or secrets.
- Commit messages brief; no emojis or em-dashes.

## Review Focus

1. **Card removal on later streets:** when the flop, turn or river is revealed, combos that contain a board card must get probability 0 and the range renormalised. `RangeTracker::reset` only blocks the initial board.
2. **Utility accounting from engine chips, not vocab sizes:** `hero_put` and `opp_call` are measured on a cloned state (all-in caps, min-raise rules). A bet that puts the opponent all-in for less than the full raise must use the capped call amount.
3. **Fold is only chosen when legal:** facing no bet (`to_call() == 0`), max U is never negative (check has U = wp·pot ≥ 0), so LBR checks, never folds.
4. **Win probability counts ties as half** and averages over every remaining board run-out exactly on flop/turn/river.
5. **Zero-mass ranges:** if every combo has probability 0 after an observation (off-support line), `RangeTracker` keeps the prior; LBR must still produce a legal action.

```cpp
struct LbrConfig {
    std::array<bool, 4> act_streets{false, false, true, true};  // preflop, flop, turn, river
    bool fold_call_only = false;     // true: consider only fold and check/call ("fc")
    int preflop_wp_samples = 500;    // sampled 5-card boards for preflop win probability
    bool uniform_opponents = false;  // test hook: opponent model and play are uniform
    int num_threads = 0;             // run(): 0 = hardware concurrency
    uint64_t seed = 1;
};

class LbrEvaluator {
public:
    LbrEvaluator(const BlueprintStrategy& strategy, const ActionVocab& vocab,
                 const EngineConfig& cfg, LbrConfig lbr_cfg);
    // Showdown win probability (ties count 1/2) of `hero_hole` against
    // `range` (1,326 combo weights, RangeTracker indexing; need not be
    // normalised; blocked combos ignored) given `board` (0, 3, 4 or 5 cards):
    // exact over all run-outs for 3/4/5 cards, `preflop_wp_samples` boards for 0.
    double win_probability(const std::array<int, 2>& hero_hole,
                           const std::vector<int>& board,
                           const std::vector<double>& range,
                           std::mt19937_64& rng) const;
    // One LBR decision for `hero` at `state` given the opponent range.
    // Returns a legal vocab index; -1 if `state` is terminal or not hero's turn.
    int decide(const EngineGameState& state, int hero,
               const std::vector<double>& range, std::mt19937_64& rng) const;
};
```

- Python: `sixmax.LbrConfig(*, act_streets=[2, 3], fold_call_only=False, preflop_wp_samples=500, uniform_opponents=False, num_threads=0, seed=1)` (act_streets given as a list of street numbers 0-3); `LbrEvaluator(strategy, vocab, cfg, lbr)`; `ev.win_probability(hero_hole, board, range, seed=1)`; `ev.decide(hand_state, hero, range, seed=1)` where `hand_state` is a `HandState` already at hero's decision.

**Algorithm (`decide`), for the engine:**
- Not an acting street (`!act_streets[street]`): return the legal Check or Call index.
- `pot = state.pot()`, `asked = state.to_call()`, `wp = win_probability(hero hole, board, range)`.
- Candidates: the Check or Call action with `U = wp*pot - (1-wp)*asked`. Unless `fold_call_only`, every other legal Bet/AllIn action `a`:
  - `next = state` with `a` applied; `hero_put` = hero's `total_bet` in `next` minus in `state`; `opp_call = next.to_call()` (the engine caps it by stack).
  - For each combo `h` with `range[h] > 0` and not blocked by hero's cards or the board: probe `next` with the opponent's hole set to `h`, `pf_h` = blueprint probability of the opponent's Fold action at `next` (0 if fold is illegal). `fp = Σ range[h]·pf_h / Σ range[h]`; `range'[h] = range[h]·(1 - pf_h)`.
  - `wp' = win_probability(hero, board, range')` (if `Σ range' == 0`, `U = pot`).
  - `U(a) = fp*pot + (1-fp)*(wp'*(pot + opp_call) - (1-wp')*hero_put)`.
- If the best U > 0, or Fold is illegal: return the best candidate (ties: lowest vocab index). Otherwise return the Fold index.
- Performance: compute the per-combo showdown result vector once per decision (win=1, tie=0.5, loss=0 averaged over run-outs), so `win_probability` for any reweighted range is a dot product. A private helper is fine; the public `win_probability` must give identical numbers.

**`RangeTracker::remove_blocked(const std::vector<int>& cards)`:** zero every combo containing one of `cards`, renormalise; if that leaves zero mass, keep the prior.

```cpp
struct LbrReport {
    int decks = 0;
    std::array<double, 2> seat_bb100{};    // LBR mean winnings per seat
    std::array<double, 2> seat_stderr{};
    double bb100 = 0.0;                    // duplicate: mean over decks of the two seats' average
    double stderr = 0.0;

};
LbrReport LbrEvaluator::run(int decks, uint64_t seed);
```

- Python `ev.run(decks, seed)` returns a dict with keys `decks, seat_bb100, seat_stderr, bb100, stderr, per_deck`.

**Algorithm (`run`):**
- Deck `d`: shuffle 0..51 with `std::mt19937_64(seed * 1000003 + d)` (as today). For hero in {0, 1}: one hand with LBR in seat `hero` and the blueprint in the other seat, button 0 as today. Per-hand RNG `std::mt19937_64(seed * 7919 + d * 131 + hero * 17 + 1)` drives both the opponent's sampled actions and preflop board sampling.
- Hand loop: `RangeTracker` reset with an empty board and hero's hole. Before each LBR decision and each opponent action, call `remove_blocked(board)` for newly revealed board cards. Opponent turn: sample from `blueprint_probs` (uniform when `uniform_opponents`), then `observe` with the pre-action state (in uniform mode, update with uniform likelihood over the legal mask). LBR turn: `decide`.
- Value: LBR's `payoffs()[hero]` in BB, times 100 for BB/100. Per deck the duplicate value is the mean of the two seats.
- Threads: decks are split across `num_threads` workers; each deck's result depends only on `(seed, d)`. Aggregate in deck order.

**Driver (`scripts/eval_sixmax_lbr.py`):** flags `--checkpoint`, `--config`, `--decks` (default 2000), `--seed`, `--act-streets` (default `2,3`; parsed to a list of ints in 0-3), `--fold-call-only`, `--preflop-wp-samples` (500), `--threads` (0), `--uniform-opponents`, `--stack-bb`, `--csv`. Print the duplicate value and each seat as BB/100 with a 95% CI, and the duplicate value also in mBB/h (×10). CSV columns: `checkpoint,act_streets,fold_call_only,decks,bb100,stderr,seat0_bb100,seat1_bb100`.
